# Squeek Arena

A Pokemon-style quiz battle game built on Squeekchain, the hamster-powered toychain on Ethereum Sepolia.

Pick a trainer, connect your wallet (one gacha pull per wallet address, recorded locally in the browser), and open your gacha box (one box in a thousand hides AURUM, the rare hamster that attacks directly with no quiz), and climb a four-boss ladder against Squeektoshi: Lv 5, MK-II Lv 25, MK-III Lv 50, PRIME Lv 100. Questions come from real Squeekchain facts plus live questions generated from the public API, and every boss gets an attack buff while Squeektoshi is really running on his wheel. Beating bosses earns local game tokens (100 per boss, 1000 for PRIME) that buy extra gacha pulls in the Shop. Beat PRIME and you are certified Squeekchain fams.

Static site, no backend, no wallet. Progress is stored locally in the browser and is never claimed to be onchain.
